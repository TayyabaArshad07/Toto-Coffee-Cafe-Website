# Toto Cafe

Toto Cafe is a modern coffee shop landing page and menu experience designed to capture the warmth, comfort, and elegance of a boutique café. The project combines a premium visual style with responsive layouts, curated product sections, and an interactive shopping experience.

## Overview

This website presents a complete front-end coffee brand experience with:

- a refined hero section and café branding
- a menu showcase with category filters
- a modern product grid with pricing and descriptions
- an interactive cart drawer and mock checkout flow
- a gallery highlighting the café atmosphere and signature items
- responsive behavior for desktop and mobile screens

## Brand Identity

Toto Cafe focuses on the idea of "Good coffee, slow moments." The visual design emphasizes warm earthy tones, soft contrast, elegant typography, and a welcoming atmosphere that feels premium but approachable.

## Features

- Responsive, mobile-friendly layout
- Smooth scrolling navigation
- Product filtering by category
- Add-to-cart functionality with quantity controls
- Checkout form with pickup and dine-in selection
- Story, gallery, and testimonial sections
- Clean, maintainable front-end structure

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### Installation

```bash
npm install
```

### Run in Development Mode

```bash
npm run dev
```

Then open the local URL shown in the terminal in your browser.

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Scripts

- `npm run dev` – starts the Vite development server
- `npm run build` – generates a production-ready build
- `npm run preview` – previews the final build locally

## Customization

The project is designed to be easy to customize. You can update:

- brand text and headings in the HTML
- menu items and pricing in `script.js`
- color palette and page styling in `styles.css`
- page content and layout sections in `index.html`
- café photography in the `images/` directory

## Notes

This project is a front-end demonstration and mock ordering experience. It is ideal for portfolio work, café branding presentations, or further expansion into a full online ordering system.
